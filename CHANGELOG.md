# Changelog

## 0.1.0 — 2026-10-30

First public release.

- **Menu bar:** CPU, memory and disk usage, network speed, date and time in one compact block. During an incident, a temperature, battery or Docker item appears next to it.
- **Panel:** one sentence on what's going on right now. When something is wrong, it names the culprits; below that come six summary cells and a few non-urgent suggestions.
- **Incidents:** sustained CPU load, memory pressure, low disk space, a busy or failing Docker container, heat and fast battery drain, each with its culprits.
- **Monitor window:**
  - Overview, CPU, Memory, Disk, Network, Docker and System sections.
  - Charts for 10 minutes, 1 hour, 24 hours and 7 days.
  - Processes grouped by app, project and dev server.
- **Disk:**
  - A map of your home folder.
  - Select items across folders, then move them to the Trash or delete them permanently.
  - Folders macOS needs are protected.
- **Docker:**
  - Containers grouped by compose project, with CPU, memory and disk use.
  - Restart or stop a container.
  - Clean up unused volumes and images.
- **System:** chip temperature and fans, power and battery health, GPU load and the apps using the most energy.
- **Languages:** English and Turkish, switchable from the panel; follows the system language by default.
